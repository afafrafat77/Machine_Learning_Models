# Gradient Descent Optimizers for Multiple Features

## Objective
This project implements and compares four types of Gradient Descent optimization algorithms for a multiple-feature dataset:

1. **Batch Gradient Descent (BGD)**
2. **Stochastic Gradient Descent (SGD)**
3. **Mini-Batch Gradient Descent (MBGD)**
4. **Momentum Gradient Descent (MGD)**
